## Portfolio scope

The IMPERIAL Core design is a **founder-led digital corporation of Universal Nano Core Agents (NCA)**, targeting **1–1,000,000,000 agent identities** as a future research architecture. A **single human founder** develops with LLM assistance. Technical NCA identities are not humans, shareholders or granted legal officers. The canonical intelligence core is **VELEON**. A proposed U.S. holding company with **10,000,000 authorized shares** is a separate unexecuted legal blueprint.

- Maintained **SHPAIZMAN** as an independent project and corporate/token boundaries for the IMPERIAL Core group.

## Remaining enterprise-quality gaps

1. **Attribution and source inventory:** Classify original author contributions, imported projects and license obligations, plus resolve duplicate/legacy repositories.
2. **Repository public/private safety:** Independently review public source for proprietary instructions/secrets; adjust classification only with correct owner permissions.
3. **Executable verification:** For code repos add real CI, deterministic tests, dependency checks, secret scanning and documented reproducible outputs.
4. **Architecture contracts:** Document runtime domains, interfaces, auth, resource budgets and human approval, without claiming they are deployed.
5. **Independent security QA:** Run real tests and track results against exact commit SHA (never copy claimed PASS numbers as newly verified).
6. **Release engineering:** Add semver, changelog, signed/approved releases, rollback, SLOs and deployment evidence when product maturity justifies them.
7. **Legal IP strategy:** Distinguish copyrights, open-source licenses, invention disclosures and **filed/granted patents**. Avoid publishing patent-sensitive enabling details pre-counsel.
8. **Corporate and digital assets:** Do not imply that proposed 10M corporate shares were issued or that private token wallets became company property.

## Acceptance rule

**No evidence → no verified claim.** An added enterprise policy document is the **start** of compliance, not proof of completion. Standard checks require independently reviewable results for E0–E6.
