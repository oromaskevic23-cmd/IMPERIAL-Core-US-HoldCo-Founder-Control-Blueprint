# Security Policy — IMPERIAL Core Architecture Repository

**Scope:** Public design documents, static founder webpage, provenance and technical architecture.

- Do **not** place API keys, passwords, wallet seed phrases, private keys, credentials, privileged security configurations or sensitive personal data in issues, pull requests or Git history.
- For security-sensitive matters, use an authenticated private channel to the repository owner; do not disclose exploit details in a public issue.
- Report reproducible observations without exploiting infrastructure you do not own or have explicit authorization to test.
- Proposed safeguards: Zero Trust, Deny by Default, Fail Closed, AI Passport, scoped agent permits and Approval Gateway. Their presence in public documentation is **not** proof of runtime enforcement.
- For IP-sensitive patent disclosures, seek professional advice before publication; this repository is public and **not** confidential.

This is a publication and reporting policy. It is not a completed security audit.
